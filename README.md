## 🎯 Fitur Utama

### 🛒 Sistem Belanja
- ✅ **Menu Picker** - Pilih produk
- ✅ **Shopping Cart** - Keranjang dengan sidebar real-time updates
- ✅ **Quantity Management** - Tambah/kurangi jumlah pesanan
- ✅ **Cart Persistence** - Keranjang tersimpan di localStorage

### 🔐 Autentikasi & Keamanan
- ✅ **Email/Password Auth** - Sistem login & register 
- ✅ **Session Management** - Auto-logout & redirect
- ✅ **Protected Routes** - Checkout hanya untuk user terautentikasi
- ✅ **Auth Modal** - Pop-up login on-demand tanpa redirect

### 📱 User Interface
- ✅ **Responsive Design** - Mobile-first, dioptimalkan untuk semua ukuran layar
- ✅ **Smooth Animations** - Framer Motion untuk transisi halus
- ✅ **Product Images** - Display gambar produk dengan responsive sizing
- ✅ **Dark Mode Ready** - Tailwind CSS dark mode support

### 💳 Checkout & Pembayaran
- ✅ **Order Form** - Form pengiriman (nama, phone, address, city, notes)
- ✅ **Order Summary** - Review produk & total sebelum checkout
- ✅ **WhatsApp Integration** - Kirim pesanan via WhatsApp
- ✅ **Database Storage** - Simpan order ke Supabase

### 🎨 Menu & Katalog
- ✅ **Featured Products** - "Menu Unggulan" slider auto-rotate
- ✅ **Product Grid** - "Produk Lainnya" dengan grid responsif
- ✅ **Category Filter** - Filter by Kopi Panas, Dingin, Specialty
- ✅ **Product Details** - Harga, deskripsi, gambar, diskon

## 🛠 Tech Stack

### Frontend
| Technology | Versi | Purpose |
|-----------|-------|---------|
| **Next.js** | 15.5.6 | React framework, SSR & SSG |
| **React** | 19.0.0 | UI library |
| **Tailwind CSS** | 3.4.1 | Utility-first CSS |
| **Framer Motion** | 11.18.2 | Animations & transitions |
| **React Intersection Observer** | 9.15.1 | Scroll animations |

### Backend & Database
| Technology | Purpose |
|-----------|---------|
| **Supabase** | PostgreSQL database + Auth |
| **Next.js API Routes** | Backend endpoints |
| **Supabase Auth** | Email/password authentication |

### Tools
| Tool | Purpose |
|------|---------|
| **ESLint** | Code linting |
| **PostCSS** | CSS preprocessing |
| **Turbopack** | Next.js bundler |
